# maat, copied into this repository

This folder is a copy of maat {{maat_version}}, the workflow this repository
runs. The tools in `bin/` need Python 3 and nothing else.

Do not edit files here. A change belongs in maat itself and arrives by an
update, which replaces this copy.

The `.gitignore` here keeps this copy tracked when the repository's own
`.gitignore` ignores `lib/` or `bin/`.

The skills a session uses are under `.claude/skills/`: `maat-method`,
`maat-lessons` and `maat-update`.

To update, see the `maat-update` skill.
